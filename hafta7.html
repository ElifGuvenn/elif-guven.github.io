Bootstrap ve JavaScript ile Etkinlik Kayıt Sayfası

Bu sayfada Bootstrap ile responsive bir arayüz tasarlanır; JavaScript ile tema değiştirme ve form verilerinden başvuru özeti üretme işlemleri yapılır.

Başvuru Formuna Git

Neler Kullanıldı?

  • Bootstrap CDN – hazır bileşenler
  • Grid sistemi – responsive yerleşim
  • JavaScript DOM etkileşimi
  • classList.toggle – tema değiştirme
  • innerHTML – dinamik içerik
Atölye İçerikleri

Bootstrap bileşenleri kullanılarak tasarlanmış örnek kartlar.

01
Responsive Tasarım

Container, row, col yapıları ile farklı ekranlarda uyumlu görünüm oluşturulur.

02
Form Yapıları

Bootstrap form-control, form-select ve form-check sınıfları kullanılır.

03
JavaScript Etkileşimi

Form gönderildiğinde özet kartı oluşturulur; tema butonu sayfa görünümünü değiştirir.
